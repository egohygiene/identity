# License inventory and SBOM policy

Every tagged Identity release generates two machine-readable supply-chain
records from the committed source and locked dependency graph:

- `identity-<version>-license-inventory.json` lists each resolved Cargo package,
  version, source, and declared SPDX license expression. The release fails if a
  package has no declared license.
- `identity-<tag>.spdx.json` is the release SPDX SBOM generated by the pinned
  Syft action. It complements the inventory with a standard interchange
  format.

Both files are release assets and are covered by the release `SHA256SUMS`.
They are evidence for the dependency policy; they do not substitute for a
maintainer's license-compatibility decision when adding or upgrading a
dependency. See [the dependency policy](../DEPENDENCY_POLICY.md) for admission,
review, and replacement requirements.
