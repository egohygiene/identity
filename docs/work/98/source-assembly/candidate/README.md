active incomplete candidate. It stages option A and the proposed `product` /
`core` + `tokens` + `metadata` selection so the remaining governance gaps are
concrete. None of those unselected choices becomes adopted through this copy.

native visual records retain `reviewedAt: null`, so authoritative validation
must remain invalid until an actual explicit packet review supplies its time
and scope. No guessed midnight or approval-shaped synthetic value is inserted.

palette. The exact local layer supplies nine original records with the explicit
`color.text.default` mapping. Their original review-only metadata remains in the
copied bytes. Both guidance declarations stay null; optional public usage is
staged separately in [the packet](../README.md) and is not advertised.

unchanged. No compiler output or release asset is present in this consumer.
