# Proposed Identity self-source

This is a **manually prepared, incomplete source candidate**, not the
repository's canonical `.identity/`, an initializer run, a validated identity,
an approved Brand Kit or a release artifact. No generation was performed.

Project fields are drawn from existing Identity publication configuration;
`kind: product` is a proposed classification requiring owner confirmation.
No organization snapshot is invented: the manifest's layer list remains empty.
Profiles are a proposed core/tokens/metadata starting selection, not an owner
adoption. Public usage and voice are unadopted; approval/provenance arrays are
empty. These omissions deliberately keep readiness incomplete.

The existing emblem/lockup are copied **byte-for-byte into candidates/masters**
as proposed canonical selections. Their generated-output provenance does not
give them new source rights or approval subjects. The actual governed Kern
source/package remains untouched in its existing location and inventory.

identify exact source choices and missing facts. Promote material to `sources/`
and supply governance only after actual owner evidence. Then validate with the
