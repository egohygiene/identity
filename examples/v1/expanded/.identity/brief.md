# Example Expanded brief

This is fictional fixture data for learning the source contract. The artwork,
reviewer, review dates, URLs, rights statements and approved states demonstrate
contract shape; they provide no real project approval or publication authority.

The repository demonstrates local organization defaults and one final product
layer. Only core, tokens and metadata are selected. Omitted guidance is explicit
in the minimal example. The expanded example adds public voice, usage and a
Press Kit using those existing canonical source boundaries. Neither example
establishes a complete public Brand Kit or verifies a deployed consumer.
