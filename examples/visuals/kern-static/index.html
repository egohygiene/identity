Kern: a static Brand Kit example

Kern is Identity's calm guide. He accompanies this visible description; the image carries no status, instruction or navigation by itself.

Choose the reviewed variant

  • Full PNG: 768 × 1152 pixels; use at 320 CSS pixels or wider.
  • Portrait PNG: 512 × 512 pixels; use at 160 CSS pixels or wider.
  • Icon PNG: 256 × 256 pixels; use at 96 CSS pixels or wider.

Use the portrait or icon on smaller surfaces. Keep the approved crop and pair it with meaningful text.

Static and reduced motion

This example has no animation, transitions, autoplay or script. The same approved static portrait is used for reduced-motion presentation. Any later motion needs its own reviewed purpose and fallback.
