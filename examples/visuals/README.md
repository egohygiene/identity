# Optional visual examples

[Kern's static mascot example](kern-static/README.md) uses Identity's existing
approved character, exact packaged PNG variants and source-owned usage/rights.
It includes an offline HTML consumer with meaningful text and links, the
reviewed portrait alternative text and required attribution.

This is an opt-in source-checkout example. Existing minimal v1 consumers remain
unchanged. Current source availability is separate from a published release;
Kern is absent from historical `v1.0.0`. See the
[category inventory and scope](../../docs/consumers/OPTIONAL_VISUALS.md).
